# Ticket to Ride RL Lab — Steampunk Workbench Suite Brief

## Job & Audience
- **Visitor Mode:** `Operate`
- **Audience:** RL researchers, machine learning engineers, and algorithmic game theorists.
- **Task:** Inspect board game mechanics with full geographic clarity, analyze neural network policy/value logits and action masks in real-time, scrub game histories counterfactually, and monitor live training / Elo tournament matrices.

## Outcome & Proof
- High-clarity vector geographical board (North America/USA continent outline, coastlines, Great Lakes, engraved topography, compass rose) ensuring clear legibility of the 36 cities and 100 routes.
- Synchronized Brain-to-Board hover links and neural action masking.
- Immersive Victorian Steampunk Cartographer & Analytical Laboratory UI (parchment grounds, brass bezels, rivet corners, steam pressure gauges, telegraph ticker logs).

## Selected Direction & Visual System
- **World:** Victorian Steampunk Cartographer & Analytical Laboratory.
- **Palette:** Aged parchment paper (`#F6EEDF`, `#E8DAC1`, `#D8C4A2`), deep sepia/charcoal ink (`#23140C`, `#3D2617`, `#5A3822`), antique brass (`#B8860B`, `#D4AF37`), burnished copper (`#CD7F32`), steel rivet accents (`#3A322C`), and vibrant route jewel colors (Ruby `#B91C1C`, Sapphire `#1D4ED8`, Emerald `#15803D`, Amber `#D97706`, Orange `#C2410C`, Amethyst `#7E22CE`, Carbon `#1E1B18`, Ivory `#F5F0E6`, Locomotive `#E11D48`).
- **Typography:** Display: *Cinzel Decorative* / *Playfair Display*; UI Body: *Crimson Pro*; Technical/Telemetry: *JetBrains Mono* / *Courier Prime*.
- **Topology:** Dense dockable split-pane workbench with brass instrument frames, steam manometer value gauge, telegraph frequency sliders, and chronometer scrubber transport.

## Scope & Boundaries
- Full Web Lab frontend suite (`frontend/src/`).
- 100% deterministic Python backend preserved; zero client-side logic divergence.
